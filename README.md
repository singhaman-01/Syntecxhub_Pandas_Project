# Syntecxhub Project 2 – Pandas CSV Reader & Basic Analysis

## Project Overview

This project demonstrates basic data analysis using Python and Pandas.

A sales dataset containing 1,000 records was loaded from a CSV file into a Pandas DataFrame. The dataset was inspected, analyzed, filtered, and exported into new files.

## Tools & Technologies

- Python
- Pandas
- CSV
- Excel
- VS Code
- GitHub
## Dataset

The dataset contains 1,000 sales records with information such as:

- Order ID
- Order Date
- Customer ID
- Product
- Category
- Sales
- Profit
- Payment Method
- Rating

## Tasks Performed

1. Loaded the CSV dataset using Pandas.
2. Displayed the first 5 records using `head()`.
3. Displayed the last 5 records using `tail()`.
4. Checked data types of all columns.
5. Calculated:
   - Mean Sales
   - Median Sales
   - Minimum Sales
   - Maximum Sales
   - Number of Sales Records
6. Filtered high-value orders where Sales > 50,000.
7. Selected specific columns for analysis.
8. Performed row and column slicing.
9. Exported filtered data to CSV.
10. Exported selected data to Excel.

## Key Result

The dataset contains 1,000 sales records. The analysis demonstrates how Pandas can be used to efficiently read, inspect, filter, analyze, and export structured data.

## Files

- `project2_pandas.py` – Python analysis script
- `syntecxhub_sales_data_1000.csv` – Dataset
- `high_value_orders.csv` – Filtered high-value orders
- `selected_sales_data.xlsx` – Selected sales data
